# GatchaGames — Transcendence

Application de cartes à collectionner autour du jeu vidéo.

## Frontend

Le frontend React, TypeScript, Vite, Tailwind CSS et Motion se trouve dans `frontend/`.

Utiliser Node.js 20.19 ou plus récent, compatible avec la CI du frontend.

```sh
cd frontend
npm ci
npm run dev
```

Commandes disponibles dans `frontend/` : `npm run build`, `npm run lint` et `npm run preview`.

Les fichiers Markdown du frontend restent en local et sont exclus du suivi Git.
Le frontend utilise actuellement des données de démonstration locales.
